# JUEGO-DE-PROGRAMACIÓN-YESSENIA
Creación de un juego en base de lo aprendido:
Fase 1: Análisis
En esta etapa se estudian y detallan los requerimientos funcionales y no funcionales del videojuego. Se definen las reglas de juego, las acciones del jugador, la interfaz, el rendimiento y la experiencia general antes de iniciar la programación. También sobre lo que trata y sobre que tipos de objetivos u objetos serán necesarios.

Fase 2: Diseño
Se elaboran los diagramas de flujo para representar la secuencia de los eventos y la lógica del sistema. Además, se realiza el diseño de la arquitectura con Programación Orientada a Objetos, definiendo clases principales y clases derivadas con sus respectivos atributos y métodos.

Fase 3: Desarrollo
Se escribe el código en el lenguaje de programación Python, aplicando los conceptos aprendidos durante el ciclo escolar. Se integran estructuras de datos, lógica de interacción, gestión de eventos y detección de colisiones para dar vida al videojuego.

Fase 4: Implementación
Se muestra el entorno de trabajo en Visual Studio Code y se realiza la ejecución del programa. En este punto se verifica el correcto funcionamiento del código, la respuesta de los controles y la fluidez del videojuego en tiempo real.
